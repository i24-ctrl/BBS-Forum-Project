# 校内BBS论坛系统数据库设计文档

## 1. 设计原则

- 采用 InnoDB 引擎，保证事务与外键支持
- 使用 utf8mb4 字符集，支持表情和多语言
- 关键字段添加索引，提高查询效率
- 通过逻辑删除保留历史数据

## 2. ER 关系说明

### 2.1 实体关系

- `user` 与 `post`：一对多，一个用户可发布多个帖子
- `board` 与 `post`：一对多，一个板块可包含多个帖子
- `post` 与 `reply`：一对多，一个帖子可有多个回复
- `reply` 与 `reply`：一对多，支持楼中楼回复
- `user` 与 `demand`：一对多，一个用户可发布多个悬赏需求
- `user` 与 `score_record`：一对多，一个用户可产生多条积分记录

### 2.2 ER图文字版

```text
user 1 ─── n post
board 1 ─── n post
post 1 ─── n reply
reply 1 ─── n reply
user 1 ─── n demand
user 1 ─── n score_record
```

## 3. 主要数据表设计

### 3.1 用户表 `user`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| username | varchar(50) | 用户名，唯一 |
| password | varchar(100) | BCrypt 密码 |
| real_name | varchar(50) | 真实姓名 |
| phone | varchar(20) | 手机号 |
| email | varchar(100) | 邮箱 |
| work_place | varchar(100) | 工作地点 |
| job_nature | varchar(50) | 工作性质 |
| avatar | varchar(255) | 头像 |
| role | tinyint | 0普通用户/1管理员 |
| status | tinyint | 0待审核/1正常/2禁用 |
| score | int | 可用积分 |
| frozen_score | int | 冻结积分 |
| version | int | 乐观锁版本 |
| login_count | int | 登录次数 |
| last_login_time | datetime | 最后登录时间 |
| deleted | tinyint | 逻辑删除 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

### 3.2 板块表 `board`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| name | varchar(100) | 板块名称 |
| description | varchar(500) | 描述 |
| icon | varchar(255) | 图标 |
| sort_order | int | 排序 |
| post_count | int | 帖子数 |
| status | tinyint | 0禁用/1正常 |
| deleted | tinyint | 逻辑删除 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

### 3.3 帖子表 `post`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| board_id | bigint | 所属板块ID |
| user_id | bigint | 作者ID |
| title | varchar(200) | 标题 |
| content | longtext | 富文本内容 |
| view_count | int | 浏览量 |
| reply_count | int | 回复数 |
| is_top | tinyint | 0普通/1板块置顶/2全局置顶 |
| is_essence | tinyint | 是否精华 |
| status | tinyint | 0待审核/1正常/2违规下架 |
| deleted | tinyint | 逻辑删除 |
| last_reply_time | datetime | 最后回复时间 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

#### 索引与约束

- `idx_board_id(board_id)`
- `idx_user_id(user_id)`
- `idx_status_top_time(status, is_top, create_time)`
- 外键 `fk_post_board` 关联 `board(id)`
- 外键 `fk_post_user` 关联 `user(id)`

### 3.4 回复表 `reply`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| post_id | bigint | 帖子ID |
| user_id | bigint | 回复者ID |
| parent_id | bigint | 父回复ID，支持楼中楼 |
| floor | int | 楼层号 |
| content | text | 回复内容 |
| status | tinyint | 0待审核/1正常 |
| deleted | tinyint | 逻辑删除 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

### 3.5 需求表 `demand`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | bigint | 发布者ID |
| title | varchar(200) | 需求标题 |
| content | longtext | 需求内容 |
| score | int | 悬赏积分 |
| status | tinyint | 0进行中/1已解决/2已关闭 |
| resolver_id | bigint | 解决者ID |
| adopt_reply_id | bigint | 采纳回复ID |
| resolve_time | datetime | 解决时间 |
| deleted | tinyint | 逻辑删除 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

### 3.6 积分流水表 `score_record`

用于记录积分冻结、释放、奖励和扣减过程，便于追踪积分变化。

## 4. 数据一致性设计

- 发帖成功后更新 `board.post_count`
- 删除帖子时回滚板块帖子数
- 回复新增时更新 `post.reply_count` 和 `last_reply_time`
- 悬赏采纳时更新需求状态与积分变化

## 5. 数据安全设计

- 用户密码采用 BCrypt 加密存储
- 删除数据采用逻辑删除字段
- 通过外键保证核心数据关系完整性
- 通过事务保证积分和状态更新一致性

## 6. 数据库设计小结

本库设计围绕用户、板块、帖子、回复和悬赏五个核心业务对象展开，结构清晰，满足论坛系统主要功能需求，并兼顾后续扩展。
