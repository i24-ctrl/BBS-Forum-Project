**实体及主要属性**

1.  **用户（user）**：id, username, password, role, status, score, frozen_score, ...
2.  **板块（board）**：id, name, description, post_count, status, ...
3.  **帖子（post）**：id, board_id, user_id, title, content, view_count, reply_count, is_top, is_essence, ...
4.  **回复（reply）**：id, post_id, user_id, parent_id, floor, content, ...
5.  **需求悬赏（demand）**：id, user_id, title, content, score, status, resolver_id, adopt_reply_id, ...
6.  **需求回复（demand_reply）**：id, demand_id, user_id, content, ...
7.  **积分记录（score_record）**：id, user_id, type, amount, balance, source_type, source_id, ...
8.  **管理员日志（admin_log）**：id, admin_id, action, target_type, target_id, ...

**实体间关系**

- **用户** 1 : N **帖子**（一个用户发多个帖子）
- **用户** 1 : N **回复**（一个用户发多个回复）
- **用户** 1 : N **需求**（一个用户发多个悬赏）
- **用户** 1 : N **需求回复**
- **用户** 1 : N **积分记录**
- **用户** 1 : N **管理员日志**（管理员操作）
- **板块** 1 : N **帖子**
- **帖子** 1 : N **回复**（一个帖子有多个回复）
- **回复** 1 : N **回复**（楼中楼，自关联）
- **需求** 1 : N **需求回复**
- **需求** 1 : 1 **用户**（解决者，可选）
- **需求** 1 : 1 **需求回复**（采纳的回复，可选）

| 表名  | 说明  | 引擎  | 字符集 |
| --- | --- | --- | --- |
| user | 用户账户、权限、积分、状态 | InnoDB | utf8mb4 |
| board | 论坛板块 | InnoDB | utf8mb4 |
| post | 主贴内容 | InnoDB | utf8mb4 |
| reply | 帖子回复（含楼中楼） | InnoDB | utf8mb4 |
| demand | 悬赏需求 | InnoDB | utf8mb4 |
| demand_reply | 悬赏下的回复 | InnoDB | utf8mb4 |
| score_record | 积分流水 | InnoDB | utf8mb4 |
| admin_log | 管理员操作日志 | InnoDB | utf8mb4 |

**2.2 索引设计（关键索引）**

每个表的索引已在建表语句中定义，此处总结优化查询的关键索引：

| 表   | 索引字段 | 类型  | 作用  |
| --- | --- | --- | --- |
| user | username | 唯一索引 | 登录、唯一性校验 |
| post | board_id | 普通索引 | 按板块查询帖子 |
| post | user_id | 普通索引 | 查询某用户的所有帖子 |
| post | (status,is_top,create_time) | 复合索引 | 首页帖子列表排序（按置顶+时间） |
| reply | post_id | 普通索引 | 查询某帖子的所有回复 |
| reply | parent_id | 普通索引 | 查询楼中楼子回复 |
| demand | user_id | 普通索引 | 查询某用户发布的需求 |
| demand | status | 普通索引 | 按状态筛选进行中/已解决需求 |
| score_record | user_id | 普通索引 | 查询某用户积分流水 |
| score_record | (user_id, type) | 复合索引 | 按类型筛选积分记录 |
| admin_log | admin_id | 普通索引 | 查询某管理员的操作记录 |
| admin_log | (target_type, target_id) | 复合索引 | 查询某个对象（如帖子）的操作历史 |

**2.3 外键约束与级联动作**

| 外键  | 父表  | 子表  |     | 级联更新 | 级联删除 | 说明  |
| --- | --- | --- |     | --- | --- | --- |
| fk_post_board | board | post | CASCADE |     | CASCADE | 删除板块则删除其下所有帖子 |
| fk_post_user | user | post | CASCADE |     | CASCADE | 删除用户则删除其所有帖子 |
| fk_reply_post | post | reply | CASCADE |     | CASCADE | 删除帖子则删除其所有回复 |
| fk_reply_user | user | reply | CASCADE |     | CASCADE | 删除用户则删除其所有回复 |
| fk_reply_parent | reply | reply | CASCADE |     | CASCADE | 删除父回复则删除所有楼中楼 |
| fk_demand_user | user | demand | CASCADE |     | CASCADE | 删除用户则删除其所有需求 |
| fk_demand_resolver | user | demand | CASCADE |     | SET NULL | 删除解决者时，需求中该字段置为NULL |
| fk_demand_adopt_reply | demand_reply | demand | CASCADE |     | SET NULL | 删除被采纳的回复时，需求表中置为NULL |
| fk_demand_reply_demand | demand | demand_reply | CASCADE |     | CASCADE | 删除需求则删除其所有回复 |
| fk_demand_reply_user | user | demand_reply | CASCADE |     | CASCADE | 删除用户则删除其所有需求回复 |
| fk_score_record_user | user | score_record | CASCADE |     | CASCADE | 删除用户则删除其积分记录 |
| fk_admin_log_admin | user | admin_log | CASCADE |     | CASCADE | 删除管理员则删除其日志（谨慎） |

注：ON DELETE CASCADE 用于依赖型数据（如帖子删除时回复自动删除）；ON DELETE SET NULL 用于非强制依赖（如需求被解决者删除后，需求仍保留但解决者信息丢失）。

**2.4 关键字段设计说明**

| 表   | 字段  | 设计说明 |
| --- | --- | --- |
| user | password | 存储 BCrypt 哈希值（长度60），示例中为$2b$04$... |
| user | role | 0普通用户，1管理员 |
| user | status | 0待审核，1正常，2禁用 |
| user | score / frozen_score | 可用积分与冻结积分分离（用于悬赏扣减事务） |
| user | version | 乐观锁字段，用于并发扣减积分 |
| post | is_top | 0普通，1板块置顶，2全局置顶 |
| reply | floor | 楼层号，在同一个帖子内自增且唯一 |
| reply | parent_id | NULL表示一级回复，非NULL表示楼中楼回复 |
| demand | status | 0进行中，1已解决，2已关闭 |
| score_record | type | 1获得，2支出，3冻结，4解冻 |
| score_record | source_type / source_id | 记录积分变动来源（如悬赏、帖子奖励等） |
| 所有表 | deleted | 逻辑删除标志（0未删除，1已删除） |
| 所有表 | create_time / update_time | 创建和自动更新时间戳 |
