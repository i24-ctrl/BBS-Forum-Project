# 校内BBS论坛系统需求分析文档

## 1. 项目背景

随着校园信息交流需求的增长，传统公告栏和零散群聊已难以满足师生对信息发布、讨论、互动和资源互助的需要。本项目拟开发一套校内BBS论坛系统，为校内用户提供统一的发帖、回帖、板块讨论、悬赏求助和后台管理能力。

## 2. 项目目标

- 提供统一的校园社区交流平台
- 支持帖子发布、浏览、回复、楼中楼互动
- 支持板块化信息组织，方便分类浏览
- 支持管理员对帖子、用户、板块进行管理
- 支持需求悬赏与积分流转，增强互助场景
- 通过JWT、权限控制和XSS过滤保证系统安全

## 3. 用户角色

### 3.1 普通用户
- 注册、登录、退出
- 修改个人资料
- 浏览首页、板块帖子和帖子详情
- 发布帖子、回复帖子、参与楼中楼互动
- 发布需求悬赏、查看悬赏详情、参与采纳
- 查看个人积分和积分流水

### 3.2 管理员
- 审核用户、禁用用户、恢复用户状态
- 管理板块信息
- 对帖子进行置顶、加精、违规下架、恢复正常和删除
- 查看管理员操作日志
- 对平台内容进行基础治理

## 4. 功能需求

### 4.1 用户模块

1. 用户注册
   - 用户填写用户名、密码等信息完成注册
   - 系统对用户名唯一性进行校验
   - 注册后默认状态为待审核或待处理状态

2. 用户登录
   - 用户使用用户名和密码登录系统
   - 系统签发JWT令牌用于后续访问鉴权
   - 登录后记录登录次数和最后登录时间

3. 个人资料管理
   - 用户可查看和修改个人资料
   - 支持头像、手机号、邮箱、工作地点、职业等字段

4. 积分体系
   - 用户可查看可用积分与冻结积分
   - 系统记录积分变动流水，便于追踪

### 4.2 板块与帖子模块

1. 板块浏览
   - 首页展示全部板块及概况
   - 板块支持启用与禁用状态

2. 帖子发布
   - 用户在指定板块发布帖子
   - 支持富文本内容编辑
   - 系统对内容进行清洗，防止XSS攻击

3. 帖子列表
   - 首页帖子支持全局置顶优先
   - 板块帖子支持板块置顶优先
   - 支持精华帖筛选

4. 帖子详情
   - 展示帖子正文、作者、板块、浏览量、回复数等信息
   - 浏览详情时浏览量加1
   - 展示回复列表和楼中楼内容

5. 帖子管理
   - 管理员可置顶、加精、违规下架、恢复正常和删除帖子
   - 违规下架帖子不可继续正常查看

### 4.3 回复模块

1. 用户可对帖子发表回复
2. 支持对某条回复继续回复，形成楼中楼
3. 回复楼层号自动生成并展示
4. 回复删除可通过逻辑删除方式管理

### 4.4 需求悬赏模块

1. 用户可发布悬赏需求
2. 发布时可设置积分悬赏值
3. 系统冻结发布者对应积分
4. 其他用户可参与回复
5. 发布者可采纳某条回复，系统完成积分结算

### 4.5 管理员模块

1. 用户审核与状态管理
2. 帖子状态管理
3. 板块管理
4. 管理日志记录

## 5. 非功能需求

### 5.1 安全性
- 采用JWT进行身份认证
- 使用角色权限控制管理员接口
- 使用Jsoup过滤富文本中的危险标签与属性
- 逻辑删除避免误删关键数据

### 5.2 性能
- 列表接口支持分页
- 使用MyBatis-Plus简化CRUD并提升开发效率
- 关键表建立索引

### 5.3 可维护性
- 采用分层架构，职责清晰
- 通过Mapper、Service、Controller拆分业务
- 统一返回结构与异常处理

### 5.4 可扩展性
- 预留Redis缓存能力
- 预留OpenAPI接口文档
- 模块化设计便于后续新增功能

## 6. 业务约束

- 用户名必须唯一
- 只有管理员可执行后台管理功能
- 违规下架帖子状态为2，不能在前台正常查看
- 被禁用板块不能发布新帖
- 帖子删除采用逻辑删除与部分物理管理相结合的方式

## 7. 总结

本系统围绕校园交流、信息共享和互助求助三个核心场景展开设计，覆盖用户注册登录、帖子互动、悬赏提问和后台管理等功能，适合作为Java Web课程设计和毕业设计基础项目。
