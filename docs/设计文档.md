一、系统概述

本系统采用 Spring Boot + MyBatis-Plus + Thymeleaf 的经典 Web 开发架构，前后端同项目部署，便于课程设计展示与调试。

二、总体架构

系统整体采用分层架构设计，主要包括：

表现层：Thymeleaf 页面、Controller 接口

业务层：Service 业务处理

数据访问层：Mapper 与 XML

支撑层：JWT、Redis、AOP、异常处理、拦截器

数据层：MySQL 8.0

三、技术选型

四、模块设计

4.1 用户模块

负责注册、登录、个人资料管理、积分展示等功能。

4.2 板块模块

负责板块展示、排序、状态控制和帖子归类。

4.3 帖子模块

负责发帖、编辑、删除、列表展示、详情展示、置顶、加精、违规下架与恢复正常。

4.4 回复模块

负责回复发布、楼中楼回复、楼层生成及回复树组装。

4.5 需求悬赏模块

负责需求发布、积分冻结、采纳结算和状态流转。

4.6 管理模块

负责用户审核、帖子治理、板块维护和管理员日志记录。

五、关键业务流程设计

5.1 登录认证流程

用户登录后由系统签发 JWT，前端在后续请求中携带令牌，后端通过拦截器解析并注入当前用户信息。

5.2 发帖流程

用户提交标题和富文本内容，服务端清洗 HTML 后写入数据库，同时更新板块帖子数。

5.3 帖子详情流程

请求帖子详情时，系统校验帖子状态、删除状态并完成浏览量递增，随后组装作者信息、板块信息与回复列表返回。

5.4 管理员治理流程

管理员可对帖子进行置顶、加精、违规下架和恢复正常处理，以便维护平台内容秩序。

六、安全设计

6.1 身份认证

采用 JWT 进行无状态认证。

6.2 权限控制

通过角色信息控制普通用户与管理员的操作边界。

6.3 内容安全

通过 Jsoup 清洗富文本，降低 XSS 风险。

6.4 数据安全

通过逻辑删除、事务控制和外键约束保障数据一致性。

七、部署说明

项目运行于 8080 端口，数据库为 MySQL bbs 库，上传文件默认存放于运行目录下的 upload/ 文件夹。
