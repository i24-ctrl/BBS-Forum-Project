# 校内BBS论坛系统接口设计文档

## 1. 接口规范

- 基础路径：`/api/v1`
- 返回格式统一为 `Result<T>`
- 认证方式：`Authorization: Bearer <token>`
- 管理员接口需要管理员角色
- 支持 SpringDoc Swagger UI 在线查看

## 2. 通用返回结构

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

## 3. 认证接口

### 3.1 用户登录

- `POST /api/v1/auth/login`
- 功能：用户名密码登录，返回JWT

### 3.2 用户注册

- `POST /api/v1/auth/register`
- 功能：创建新用户

## 4. 用户接口

### 4.1 获取个人资料

- `GET /api/v1/user/profile`
- 说明：返回当前登录用户资料

### 4.2 修改个人资料

- `PUT /api/v1/user/profile`
- 说明：更新头像、手机号、邮箱等信息

### 4.3 查询积分流水

- `GET /api/v1/user/score-records`
- 说明：分页查看积分变化记录

## 5. 板块接口

### 5.1 板块列表

- `GET /api/v1/boards`
- 功能：查询所有正常板块

### 5.2 板块详情

- `GET /api/v1/boards/{id}`
- 功能：查询板块信息

## 6. 帖子接口

### 6.1 首页帖子列表

- `GET /api/v1/posts?page=1&size=10&essenceOnly=false`
- 功能：查询首页帖子

### 6.2 板块帖子列表

- `GET /api/v1/boards/{boardId}/posts?page=1&size=10&essenceOnly=false`
- 功能：查询指定板块帖子

### 6.3 帖子详情

- `GET /api/v1/posts/{id}`
- 功能：查询帖子详情、回复列表、浏览量+1
- 说明：若帖子状态为违规下架，返回提示“该帖子因违规已下架，无法查看详情”

### 6.4 发帖

- `POST /api/v1/posts`
- 请求体：`PostDTO`
- 功能：创建帖子

### 6.5 修改帖子

- `PUT /api/v1/posts/{id}`
- 功能：作者或管理员修改帖子

### 6.6 删除帖子

- `DELETE /api/v1/posts/{id}`
- 功能：逻辑删除帖子

## 7. 回复接口

### 7.1 发表评论

- `POST /api/v1/posts/{postId}/reply`
- 功能：发表一级回复或楼中楼回复

### 7.2 删除回复

- `DELETE /api/v1/replies/{id}`
- 功能：删除回复

## 8. 需求悬赏接口

### 8.1 发布需求

- `POST /api/v1/demands`
- 功能：发布悬赏需求

### 8.2 需求列表

- `GET /api/v1/demands`
- 功能：查询需求列表

### 8.3 需求详情

- `GET /api/v1/demands/{id}`
- 功能：查询需求详情和回复

### 8.4 采纳回复

- `PUT /api/v1/demands/{id}/adopt`
- 功能：采纳指定回复并完成积分结算

## 9. 管理员接口

### 9.1 用户列表

- `GET /api/v1/admin/users?page=1&size=10&status=1`
- 功能：分页查询用户

### 9.2 修改用户状态

- `PUT /api/v1/admin/users/{id}/status?status=1`
- 功能：审核通过、禁用或恢复用户

### 9.3 帖子管理列表

- `GET /api/v1/admin/posts?page=1&size=10&status=2`
- 功能：分页查询全部帖子

### 9.4 帖子置顶

- `PUT /api/v1/admin/posts/{id}/top?type=2`
- 功能：设为全局置顶、板块置顶或取消置顶

### 9.5 帖子加精

- `PUT /api/v1/admin/posts/{id}/essence?flag=1`
- 功能：加精或取消精华

### 9.6 违规下架帖子

- `PUT /api/v1/admin/posts/{id}/offline`
- 功能：将帖子状态改为违规下架（status=2）

### 9.7 恢复帖子正常

- `PUT /api/v1/admin/posts/{id}/restore`
- 功能：将违规下架帖子恢复为正常状态（status=1）

### 9.8 物理删除帖子

- `DELETE /api/v1/admin/posts/{id}`
- 功能：彻底删除帖子并扣减板块帖子数

## 10. 接口设计说明

- 列表接口统一分页返回 `records/total/current/size/pages`
- 管理员接口均需要角色校验
- 帖子详情接口会对不可见状态进行拦截
- 内容富文本统一经过服务端清洗

## 11. 接口设计小结

本系统接口设计清晰，按模块划分明确，便于前后端联调与后续扩展。
