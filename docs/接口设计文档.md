**九、统一错误响应**

**Json**

{"code":400,"msg":"业务异常描述","data":null,"timestamp":1717000000000}

| **code** | **含义** |
| --- | --- |
| 200 | 成功  |
| 400 | 业务异常（参数错误、权限不足等） |
| 401 | 未认证（Token无效/过期） |
| 403 | 无权限 |
| 500 | 服务器内部错误 |
