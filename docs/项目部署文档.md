**在前后端项目开发初期，我们大多依赖localhost或127.0.0.1的本地服务调试——前端调用本地后端接口，数据存在本地MySQL，只能在自己电脑上访问。但项目开发完成后，想要让其他人（或自己）随时随地调用接口、使用服务，就必须把Spring Boot项目部署到远程云服务器上。这篇文章从「阿里云服务器购买」开始，用宝塔面板，实现 “服务器购买→环境配置→项目部署→云数据库创建”的全流程，让后端服务真正“上线可用”。**

**一、前期准备：明确核心目标与工具**

- **目标：把本地能跑的Spring Boot项目，部署到阿里云服务器，搭配云数据库，实现公网访问。**
- **必备工具/文件：**
    1.  **阿里云账号**
    2.  **已完成的Spring Boot项目（本地测试无bug，提前准备好application.yml配置文件，后续要改数据库连接）；**
    3.  **浏览器（用于操作阿里云控制台和宝塔面板）。**

**二、阿里云服务器购买流程**

**1\. 登录阿里云并进入ECS购买页**

- **打开阿里云官网（**[**https://www.aliyun.com/**](https://link.csdn.net/?target=https%3A%2F%2Fwww.aliyun.com%2F%3Flogin%3Dfrom_csdn)**），点击右上角「登录」，用手机号+验证码登录。**
- **登录后，鼠标悬停在顶部「产品」菜单，找到「云服务器ECS」，点击进入ECS产品页，再点击「立即购买」。  
      
    **

**2\. 服务器配置选型**

**（1）实例规格： “2核2G”足够**

**这个配置跑小型Spring Boot项目（无高并发）完全够用，后续不够用再升级（阿里云支持在线升级配置，不用重装系统）。**

**（2）镜像：建议选择CentOS 7.x（宝塔面板适配最佳）**

**（3）地域：选靠近用户的区域（华东1 杭州）**

**（4）网络：必须勾选公网IP**

- **「带宽计费方式」：选「按固定带宽」。**

**3\. 确认订单并支付**

- **下滑到页面底部，勾选「我已阅读并同意《云服务器ECS服务条款》」，然后点击「立即购买」；**
- **跳转支付页面，用支付宝或微信支付即可。**

**4\. 购买后找到服务器公网IP**

- **支付完成后，点击「管理控制台」，回到「云服务器ECS」页面；**
- **在「实例列表」里，找到你刚购买的服务器，记录下「公网IP地址」（116.62.191.145）——后续连接服务器、访问项目都要用到这个IP。**

**三、配置服务器与安装宝塔面板**

**1\. 使用阿里云提供的Workbench远程连接服务器实例**

- **点击「远程连接」**
- **系统会自动填写连接信息：**
- **点击「登录」**

**2\. 一键安装宝塔面板（复制命令即可）**

**在命令行里，直接复制以下命令（CentOS 7.x专用），粘贴后按回车：**

**yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh**

- **执行后，会提示“是否继续安装”，输入y（小写），然后按回车，等待5-10分钟（取决于服务器网速，期间不要关闭命令行页面）；**
- **安装完成后，命令行会输出宝塔面板的登录信息：**

**3\. 初始化宝塔面板环境（安装LNMP）**

- **打开浏览器，输入刚才保存的「外网面板地址」，输入用户名和密码登录宝塔面板；**
- **首次登录会弹出「环境安装」窗口，选择「LNMP」（Linux+Nginx+MySQL+PHP），组件版本保持默认即可（新手不用改）：**
    - **MySQL：4.7.x；**
    - **Nginx：默认最新稳定版（用于反向代理，后续可优化项目访问速度）；**
    - **PHP：默认版本（我们用Java，PHP是为了宝塔面板正常运行，不用管）；**
- **点击「一键安装」，然后耐心等待10-20分钟。  
    **

**四、在宝塔面板创建云数据库（替代本地MySQL）**

**本地项目用的是localhost的MySQL，部署到云端后，需要创建「云数据库」，让Spring Boot远程连接。**

**1\. 新建云数据库**

- **宝塔面板登录成功后，左侧菜单点击「数据库」→「添加数据库」；**
- **填写数据库信息：**
    - **数据库名：bbs；**
    - **用户名：bbs（宝塔面板为保护数据库安全，不允许使用root）；**
    - **密码：设置密码（如_Db@_Spring123，和服务器密码区分开，记在记事本上）；**
    - **权限：选「所有人」（允许Spring Boot项目远程连接）；**
- **点击「确定」，云数据库就创建完成了（列表里会显示刚创建的数据库）。  
    **

**2 将本地数据库数据导入云数据库中**

- **在宝塔面板 -「数据库」点击「导入」，选择我们项目的init.sql文件，点击确定即可**

**五、部署Spring Boot项目（从本地打包到云端运行）**

**1\. 修改Spring Boot的数据库配置**

- **打开IDEA，找到本地项目的src-main-resources下的application.yml，把数据库连接改成云数据库的信息：**
- datasource:  
    type: com.alibaba.druid.pool.DruidDataSource  
    driver-class-name: com.mysql.cj.jdbc.Driver  
    url: jdbc:mysql://127.0.0.1:3306/bbs?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai  
    username: bbs  
    password: 12345678  
    redis:  
    host: 127.0.0.1  
    port: 6379  
    password: YourSecurePassword123  
    database: 0  
    timeout: 3000ms  
    thymeleaf:  
    cache: false  
    servlet:  
    multipart:  
    max-file-size: 2MB  
    max-request-size: 10MB

**2\. 本地打包Spring Boot项目（确保是Jar包）**

- **打包项目：**
    - **IDEA用户：右侧「Maven」→展开项目→「Lifecycle」→双击clean（清除旧包），再双击package（打包新包）；**
    - **找到Jar包：打包成功后，在项目的target文件夹下，找到后缀为.jar的文件（如springboot-demo-0.0.1-SNAPSHOT.jar）——复制这个Jar包。**

**3\. 上传Jar包到阿里云服务器**

- **回到宝塔面板，左侧「文件」，点击「新建目录」，命名为springboot（用于专门存放Spring Boot项目）；**
- **找到刚打包的Jar包，直接拖拽到刚才创建l的/www/springboot目录下——等待上传完成。**

**4\. 用宝塔面板启动Spring Boot项目**

- **宝塔面板左侧菜单点击「Java项目」→「添加Java项目」；**
- **填写项目信息：**
    - **项目名称：自定义（如springboot-demo）；**
    - **项目路径：点击「选择」，找到/www/springboot目录，选中后点击「确定」；**
    - **Jar包名：点击下拉框，会自动识别目录下的Jar包（如springboot-demo-0.0.1-SNAPSHOT.jar），选中即可；**
    - **JDK版本：选择SpringBoot项目中使用的JDK版本（必须保持一致，避免兼容问题)；**
    - **端口：填8080（必须和application.yml里的server.port一致，且安全组已开放）；**
- **点击「提交」，宝塔会自动启动项目——启动后，在「Java项目」列表里，「运行状态」会显示「运行中」（如果显示“停止”，点击「启动」按钮，或查看日志排查错误）。**

**5.放行端口**

**服务器和宝塔面板必须放行端口才能让用户访问项目**

- - **宝塔面板左侧菜单点击「安全」，添加端口规则，放行8080端口（和application.yml里的server.port一致）**

- - **阿里云服务器控制台左侧菜单「安全组」🡪「管理规则」🡪「增加规则」添加所需的端口（允许访问宝塔面板8888，允许redis6379，允许mysql3306，以及备用端口80、8080、443）**

**这是最后一步，也是最关键的验证环节：**

1.  **打开任意浏览器（电脑或手机都可以），在地址栏输入：  
    _http://_** **_116.62.191.145:8080_**
