# 校内BBS论坛系统项目部署文档

## 1. 部署环境

- JDK 11+
- Maven 3.6+
- MySQL 8.0+
- Redis 6.x+
- Windows / Linux 均可部署

## 2. 环境准备

### 2.1 创建数据库

执行 `init.sql` 初始化数据库结构与基础数据。

### 2.2 修改配置文件

修改 `src/main/resources/application.yml` 中数据库与 Redis 配置：

- `spring.datasource.url`
- `spring.datasource.username`
- `spring.datasource.password`
- `spring.redis.host`
- `spring.redis.port`

### 2.3 上传目录

系统默认上传目录为应用运行目录下的 `upload/`，请确保该目录具有读写权限。

## 3. 本地启动步骤

### 3.1 拉取代码

将项目代码放入本地工作目录。

### 3.2 导入数据库

在 MySQL 中执行 `init.sql`。

### 3.3 启动 Redis

确认 Redis 服务已启动并可访问。

### 3.4 启动项目

使用 Maven 启动：

```bash
mvn spring-boot:run
```

或者打包后运行：

```bash
mvn clean package -DskipTests
java -jar target/bbs-0.0.1-SNAPSHOT.jar
```

## 4. 访问地址

- 前台首页：`http://localhost:8080/`
- Swagger UI：`http://localhost:8080/swagger-ui.html`

## 5. 部署注意事项

1. 确保数据库字符集为 `utf8mb4`
2. 确保 MySQL 与 Redis 端口可达
3. 确保 `upload/` 目录可写
4. 若部署到 Linux，建议使用 `nohup` 或 systemd 守护进程运行
5. 生产环境建议关闭 `thymeleaf.cache=false` 的开发配置并调整日志级别

## 6. 常见问题

### 6.1 数据库连接失败

检查用户名、密码、数据库地址是否正确。

### 6.2 登录后接口 401

检查前端是否携带 `Authorization` 头部，以及 JWT 是否过期。

### 6.3 上传失败

检查上传目录权限和文件大小限制。

## 7. 部署总结

该系统采用标准 Spring Boot 部署方式，配置简单，适合课程设计演示和本地运行部署。
